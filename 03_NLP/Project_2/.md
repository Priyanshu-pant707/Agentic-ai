# Document Similarity Checker
- find the similarity between two documents using TF-IDF.




## Features - 
 -upload two lext , cosines similarity score




## What is document similarity  ?

- how much the document are similar for each other.
    - 1.0 -> exactly same
    - 0.0 -> different


## TF-IDF
- term frequency
- time of the word appeared in the document

##  IDF
- inverse document frequency


``` TF-idf=TF*IDF```
