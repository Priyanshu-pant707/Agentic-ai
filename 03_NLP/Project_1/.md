# 🧹 Text Preprocessing Tool (NLP)

A beginner-friendly NLP project that converts raw text into clean,
machine-readable data using standard preprocessing techniques.

## 🚀 Features
- Text Cleaning
- Tokenization
- Stopword Removal
- Lemmatization
- Interactive UI with Streamlit

## 🛠 Tech Stack
- Python
- NLTK
- spaCy
- Streamlit

## ▶ How to Run
```bash
pip install -r requirements.txt
python -m spacy download en_core_web_sm
streamlit run app.py
