## 1️⃣ Introduction to NLP

### What is NLP?

Natural Language Processing is a field of **AI + Data Science** that enables machines to understand, interpret, and generate **human language**.

### Real‑world Applications

* Chatbots (ChatGPT, Alexa)
* Resume Screening
* Sentiment Analysis (Twitter, Reviews)
* Spam Detection
* Machine Translation
* Voice Assistants

### NLP Pipeline

1. Text Collection
2. Text Cleaning
3. Tokenization
4. Stopword Removal
5. Feature Extraction
6. Model Training
7. Evaluation

---

## 2️⃣ Text Preprocessing (VERY IMPORTANT)

### 2.1 Text Cleaning

* Lowercasing
* Removing punctuation
* Removing numbers
* Removing HTML tags

### 2.2 Tokenization

Breaking text into smaller units

* Word Tokenization
* Sentence Tokenization

### 2.3 Stopwords

Common words with less meaning
Example: is, the, am, are

### 2.4 Stemming vs Lemmatization

| Stemming  | Lemmatization   |
| --------- | --------------- |
| Faster    | Accurate        |
| root form | dictionary form |

## 3️⃣ Feature Extraction Techniques

### 3.1 Bag of Words (BoW)

* Counts word frequency
* Order ignored

### 3.2 TF‑IDF

TF = Term Frequency
IDF = Inverse Document Frequency

More importance to **rare but useful words**

### 3.3 Word Embeddings

* Word2Vec
* GloVe
